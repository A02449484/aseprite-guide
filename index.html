Introduction

Hello! This is a guide designed for beginners to Aseprite.

Aseprite is a Animated Sprite Editor & Pixel Art tool. Its main use is creating and animating pixel art drawings. It can also be used to edit images.

This guide will walk you through how to create a simple animation, edit frames, and export in different formats. It is not meant to be an in-depth guide on every feature, and checking out the online documentation is a good idea to familiarize yourself with unfamiliar features.

This guide will:

  • Show you how to use basic editing tools
  • Pick various colors
  • Teach some keyboard shortcuts
  • Briefly touch on layers
  • Walk through the basics of managing different frames
  • Explain how to export and save in different ways
  • Try to help you avoid getting too stuck or confused

This guide will not:

  • Teach you how to draw or animate well
  • Explain every feature in Aseprite
  • Cover every possible thing you could accidentally mess up
  • Explain customization options
  • Tell you how to use your images elsewhere
  • Explain how to build Aseprite from source

Part 0: Setup

Welcome to Aseprite! When you first open the software, you should see something like this.

I've shrunk my window down so it's easier to fit into the guide. Yours might look a bit different, but the introduction window should generally look something like this.

First, locate and select the "New File..." option in the top-left, next to the Aseprite logo. You should see this new pop-up:

Most of these options aren't important right now. The only ones we care about are Width and Height.

These represent how many pixels our project will have. Each pixel represents a single square which can be any color. So, with width and height at 32px by 32px, we'll have 1,024 individual squares that can be different colors.

For now, just stick with something like 32px for each option.
(This can be changed later by accessing the Sprite dropdown near the top of the workspace and selecting Sprite Size)

This is the workspace.

I'll go over all the main elements you should know.

Palette

This is the palette. It includes preset colors that you can easily pick from.
Left or right-clicking one of these colors will assign that color to the corresponding mouse button.
If you notice the small black triangle on the white color, that signifies that white is assigned to right-click. Left Click assignment is denoted by a black triangle in the top right of a color. (It's set to black in this screenshot, so it blends in.)
This left/right-click color dynamic goes for basically every color tool, including drawing, filling, and the color picker.

The buttons above the palette are used for palette management, such as:

  • Locking & unlocking the palette
  • Sorting the colors
  • Changing which palette is active
  • Saving, loading, and changing the visuals of the palette.

Color Picker

This is the color picker. It has a gradient from which you can choose whatever color you want, using the same left/right-clicking scheme. the multicolored bar underneath changes the hue. Beneath that, you can see the left and right click colors, respectively. Clicking on either one will provide you with various formats with which you can select a precise color.

The red exclamation point next to the yellow left-click color simply denotes that the color isn't part of the palette for the scene. Clicking the exclamation point will add it to the palette, but it can also be safely ignored.

Animation Timeline

This is the animation timeline, where you can edit frames and layers, and preview the animation. I'll go over more features later, but note that you can click the icons on the far-right to show/hide a preview of what you're working on, as well as show/hide the timeline.

Toolbar

This is the toolbar, which allows you to select various different drawing tools.

  • If you hover over a tool, you will be given a description including its name, the keybind to access it quickly, and differences between left/right clicking (if applicable).
  • if you left-click on a tool, that tool will be selected.
  • Some tools have extra modes that will appear when clicked, that can then be clicked to select them.

Tool Options

These are the individual options for any given tool that is selected.
Each option will give a brief description of its purpose when hovered over. The most relevant ones for our purposes will be things like:

  • Brush Size
  • Opacity
  • Tolerance (allows the paint bucket tool to affect similar colors less or more)
  • Contiguous (whether to restrict the paint bucket tool to enclosed areas)

Canvas


This is the canvas. In the middle, you can see the 32x32 area allocated to your image. outside of that, there's blank space (the purple-ish color.) There are also scrollbars you can drag.

I'll provide some helpful controls for manipulating the canvas here, although there are other methods to do the same things.

  • Scrolling on your mouse wheel will zoom in and out.
  • Clicking down your middle mouse button will allow you to pan around.
  • Dragging the seams between the left side, with the colors, or the bottom side, with the timeline, will allow you to resize these elements.

If you noticed the 4 squares in the center, that's the default transparent background. The image is actually empty right now. Each square represents an 8x8 square of pixels, and helps with measurements.

Tab List

Up here, in what I call the Tab List, we have a few different things.

  • In the top, we have a bunch of drop-down menus, with their own options.
  • Below that, there are different tabs for different files. You can click them to swap between projects that are open.
  • Way on the right, there's the small layout options button, which reveals a dropdown, and gives access to more options in how you arrange your workspace.

And that's about it for the workspace!
In case you're curious, the text in the very bottom-left of the workspace simply displays various information based on where you're hovering, such as:

  • The filename
  • Mouse location
  • Image size
  • Tool name & shortcut
  • Color information
  • etc.

Part 1: Drawing

Now that we've got all that boring stuff out of the way, it's time for the fun part!
Now you get to draw the first frame of your animation.

I'll show a process of me drawing a pretty simple image to illustrate. Feel free to experiment with the different tools. This is also a good time to mention that if you accidentally make a mistake, you can press Ctrl-Z or go to the Edit dropdown and select "Undo."


Here, I have black selected as my left color. I select the ellipse tool, and hold shift to draw a perfect circle.
The Shift key has some pretty interesting properties. It can help draw proportional shapes, resize proportionally, draw straight lines, and draw contours with more sides, as well as another use a bit later.


Next up, I select the paint bucket tool, set yellow as my left color, and click inside the circle to fill it.
(Note that if I had the "Contiguous" tool setting turned off, it would have colored the area outside my outlined circle yellow as well.)


Finally, I select the pencil tool, then the black color as my left color again, and then I simply draw the face on.

Most of the tools are relatively simple. However, there is one that is a little more complex and versatile. The Marquee tool (or other forms of selection tool) allow you to select an area and manipulate it.

First, pick the selection type you want. There's rectangular, elliptical, freeform, polygonal, and color selections.

Next, select an area using left click. (the controls can differ a bit depending on the tool.)
Once an area is selected, you can add more by holding shift and selecting again, or remove some by right clicking and marking some of the current selection. (Assuming you're on the default "Replace selection" mode.)

Now, only the selected area will be affected by any image editing. You can drag the selection around with left click to move the selection, drag the outside squares to resize, and press delete to delete the selected area.

You can also:

  • Drag the border of the selection to move it, without moving the selected pixels.
  • Copy, cut, and paste the selection either through the Edit dropdown or Ctrl-C, Ctrl-X, and Ctrl-V.
  • Flip the selection horizontally or vertically through the Edit dropdown or Shift-H and Shift-V.

Once you're done with your selection, you can remove it by pressing Ctrl-D,

Layers

In case you want your image to be a little more organized, you can add layers, which will allow you to edit, hide, or effect certain parts of your image without impeding others. To do this, go to the animation timeline, and right click on Layer 1. This will show some options. Navigate to the New... tab, and select New Layer. (Or, press Shift-N)

Here, I create a new layer. I then click on Layer 1 to select it, and select the outline of my image. I use Ctrl-X to cut, and then I click on Layer 2 to select it instead. I then use Ctrl-V to paste it onto the new layer.

As you can see, I can then use the eraser on the image, and it only effects the layer I'm currently on.

Remember, if you do use multiple layers, try to always swap to the layer you want to draw on, or you might get some confusing messes.

In case you want to make it a little easier on yourself, you can double click a layer to pull up its properties, and from there you can rename it.

Finally, in case you want to make dealing with layers a little easier, there's two very helpful buttons that will hide and lock layers.


On the left here, we have an eye symbol, that will hide a layer, and a lock symbol, which will prevent you from editing that layer. These can both be toggled on and off at will.

Part 2: Animating

Frames

Now that you have a beautiful sprite, you need to add another image to make it an animation!
To add a new frame, you can right click on the square with a 1 in it, as seen in the top-right of this image.

Once you right-click on that, either click New Frame, or New Empty Frame. (Alt-N or Alt-B)
The first option will copy your current frame into the second frame, while the other option creates a new, empty frame. Once you have a second frame, you can edit it, and it will have no effect on the first frame.

If you accidentally create too many frames, you can delete a frame by right clicking it and selecting Delete Frame, or pressing Alt-C.

If you want to move a frame, you need to click on it, and then drag the border of the frame until it snaps to a new position, as seen below.

Animation

Once you've drawn some frames, you can see what the animation looks like by clicking the triangular play button to run the animation.

You can stop the animation by clicking the same button.
If you're curious, feel free to hover over the other 4 buttons to see what they do. (Or just click them, they won't hurt you.)

Finally, if you want some frames to last for longer than others (without adding duplicates,) you can double click on a frame to open its properties. From there, you can change its Duration (Bigger number means it lasts for longer.)

Part 3: File Management

Saving

Throughout this process, you should probably be saving your project frequently. If Aseprite crashes, it usually does a good job at recovering files, but you can't be too safe.
To save your animation, either press Ctrl-S, or go to the File dropdown, click Save, and navigate to where you want to save the file. The next time you save, it will simply save in the same place.

By default, the file will save as a .aseprite file, meant for importing into Aseprite. This can be changed, although it's usually best to export other file types instead of saving.
.aseprite files will save your layers and frames, while others usually won't.

If you accidentally save your file in the wrong spot, or as the wrong format, you can use Save As... instead. (Ctrl-Shift-S)

Exporting

Now, when you inevitably want to save your file as something useful, you can use Export option. Find it under the File dropdown, and click Export As...

Here we have some options. You'll likely want to change:

  • The filename (textbox in front of Output File:)
  • The location to be saved (click the 3 dots next to the name, then "Choose File...")
  • The type (When you're editing the location, there's a file type dropdown)
  • The size (your image is likely extremely tiny. increasing the size can make it easier to see on most platforms)

Finally, hit Export. You're good to go! If you saved your animation as a gif, you should be able to view it if you have an image viewer that supports gif files.
